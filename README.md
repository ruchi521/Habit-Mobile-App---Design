In this Mobile App Design We saw the daily routine Habits , We can create Daily Routine like Workout, Drink Water, Read Book, Learning and follow the routine in grey color circle symbol indicates we can done this routine at 0 time. In yellowish color circle symbol indicates this routine ongoing, In green color circle symbol indicates this routine done at 100% completed in one day and In red color circle symbol indicates this routine in half we stop. </li>
  <li>In Habit App Design Graph Shows Daily completing task and also shows per month progress accuracy graph to analyze the data monthly routine in which habit we stop completed and current progress , progress visualization also shown based on per day routine , If we missed one day routine we can also rearrange routine set data in Rearrange Missed Habit Section.</li>
